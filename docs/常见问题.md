# 常见问题

## 下载的 ZIP 为什么不能双击启动

GitHub 的“Code → Download ZIP”是源码；普通用户应下载 Releases 里的 Windows 便携包。便携包也必须完整解压，再双击根目录“启动.cmd”。

## 没有 Python 或显卡能用吗

便携包自带 Python。没有可用 NVIDIA GPU 时选择“仅CPU”，处理速度会受电脑性能影响。无需为便携包单独安装 CUDA Toolkit；GPU 是否可用仍取决于显卡、驱动和附带运行库的兼容性。

## 需要哪些账号

普通转写不需要账号。仅从 Hugging Face 在线下载受访问条件限制的说话人模型时，需要对应账号、接受条件和读取 Token。含模型版使用完整本地模型时无需 Token。

## 模型下载失败、401/403 或一直不动

401/403 通常与未接受模型条件或 Token 读取权限有关。普通模型也无法下载时，先确认模型网站能访问、磁盘有空间且目录可写。取消后可以重试；不要把 Token 交给不明下载站。网络条件不适合时改用完整包。

## 没有声音的视频或损坏文件

程序会报告音轨读取失败，其他文件继续按任务策略处理。带有 DRM 或特殊编码的媒体不保证可读取。支持扩展名不等于保证每种内部编码都能解码。

## 输出在哪，为什么同名文件多了扩展名

输出位于你选择的文件夹，并保留输入子目录结构。`会议.mp3.txt` 和 `会议.wav.txt` 是不同媒体的结果。旧版存在歧义的输出会保留，必要时新文件使用“转写”后缀，避免覆盖旧稿。

## 中断后能从断点继续吗

“跳过已有结果”按完成的文件恢复，尚未完成的文件会重新处理。开启 JSON 后，跳过判断也会检查所需 JSON 是否存在。切换模型或语言后，旧结果不会自动失效；需要重做时选择新输出目录。

## 暂停、停止和关闭窗口有什么区别

暂停后可以继续同一任务；停止会结束任务。关闭窗口时，仍在运行的转写任务默认留在后台，界面会询问确认。请按提示处理，不要直接拔出运行目录所在磁盘。模型下载窗口关闭前会询问是否取消下载。

## 转写不准、说话人分错了

模型可能产生错字、漏字、幻觉文字或错误说话人标签。先确认语言选择和音轨质量，尝试均衡或高精度档位，再人工校对。说话人标签只表示分组，不等于身份识别。

## 如何更新

将新版本解压到新目录，先用少量文件验证。旧音频、结果和旧版本保留备份。不要把自己的 `.runtime`、Token、日志或录音放进公开发布包；Token 的加密文件也不应分享。

## 如何反馈

在 GitHub Issues 提供版本、Windows 版本、CPU/GPU、使用档位、复现步骤和已经去除隐私的报错。不要提交 Token、未经授权的录音、完整私人路径或他人个人信息。可用不含隐私的短样例复现问题。
