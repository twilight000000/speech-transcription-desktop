# 含模型完整版

适合希望一次准备好后离线使用的 Windows 用户。包含运行环境、tiny/base/small/medium 转写模型、community-1 说话人模型和 Silero 人声检测组件。

## 1. 完整下载和解压

从项目 Releases 指向的下载位置获取 **Windows-含模型.zip**。文件较大，请核对发布页的文件大小与 SHA-256。若采用分卷发布，必须下载全部分卷，放在同一目录，再用 7-Zip 打开第一卷解压。

建议预留 25 GB 空间。解压到可写的本地目录，不要直接在压缩软件内启动，也不要拆散 `app` 和 `portable_runtime` 文件夹。

## 2. 启动并选择文件夹

双击根目录 **启动.cmd**。选择存放音频、视频的输入文件夹，以及结果保存文件夹。程序会递归处理子文件夹。

第一次建议保持“均衡”；没有可用 NVIDIA GPU 时选择“仅CPU”。只需要文字时关闭“区分不同说话人”。如需说话人标签可以开启；内置模型完整时无需 Token 或在线登录。

点击 **首次使用 / 模型** 可以检查模型是否“已就绪”。完整包显示“需要下载”通常意味着没有完整解压、文件被移动，或文件损坏；请先重新核对压缩包。

## 3. 开始转写

点击 **开始转写**，查看进度；结束后点击 **打开输出目录**。TXT 带时间戳，JSON 为可选的结构化结果。不会识别视频画面或画面中的字幕。

“跳过已有结果”按文件跳过已有输出，适合批量任务中断后继续。它不是长音频逐秒断点续写：尚未完成的单个文件会重新处理。需要重新转写时选择新的输出目录，或明确关闭跳过选项。

本地模型运行无需联网。请人工检查结果，尤其是人名、数字、口音、噪声和说话人标签。
