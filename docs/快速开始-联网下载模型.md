# 联网下载模型版

适合希望只下载实际使用模型的 Windows 用户。无需自己安装 Python；包内已经包含运行环境，但首次准备转写模型需要联网。

## 1. 下载并解压

从项目 Releases 中获取 **Windows-按需下载模型.zip**。若发布页提供多个分卷，必须先全部下载到同一文件夹，再用 7-Zip 打开第一卷解压。

解压到可写、空间充足的本地目录，例如 `D:\SpeechTool`。路径不要过深，建议预留 25 GB 空间。保持 `app` 与 `portable_runtime` 文件夹并排，不要单独拖出启动文件。

## 2. 第一次启动

双击根目录 **启动.cmd**。第一次加载运行环境可能需要等待。引导窗口会列出当前设置所需模型及“已就绪 / 需要下载”。

先返回主界面选择输入和输出文件夹。“均衡”通常对应 small 模型（约 464 MiB）；高速 CPU 使用 base（约 141 MiB），高精度 GPU 使用 medium（约 1460 MiB）。CPU/GPU 档位不同，所需模型也可能变化。普通转写保持“区分不同说话人”关闭即可。

## 3. 下载所需模型

点击 **首次使用 / 模型 → 下载缺少的模型 / 重试**。文件来自 Hugging Face 官方仓库。窗口显示当前文件和下载信息，完成后校验文件 SHA-256。

下载慢或中断时可以取消，之后重试会复用已完成文件。请确认网络能访问模型网站，磁盘未满。无法访问时可改用含模型完整版，勿在未知网站输入 Token。

普通转写无需注册账号。需要在线下载说话人模型时：
1. 开启“区分不同说话人”。
2. 在引导窗口打开说话人模型授权页面，登录 Hugging Face 并接受该模型的访问条件。
3. 创建有该仓库读取权限的 Token，填入主界面的 Token 输入框。
4. 再次打开模型引导并下载。请勿在截图、反馈或网盘里分享 Token。

## 4. 开始并查看结果

模型就绪后返回主界面，点击 **开始转写**。可在“运行日志”中查看进度。完成后点击 **打开输出目录**；例如 `采访.wav` 会生成 `采访.wav.txt`，勾选 JSON 时还会生成同名 JSON。

模型准备完成后，使用同一模型可以离线运行。更换档位需要的新模型尚未下载时，需再次联网准备。
