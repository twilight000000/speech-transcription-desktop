# 隐私说明

## 数据处理

本程序在本机进行音视频解码、转写和说话人区分，不将输入音视频或转写结果提交到云端识别接口。输出保存到用户指定的目录；任务设置、控制文件和日志保存在程序的 `.runtime` 目录。

日志可能包含文件名、路径、错误信息和处理进度；输出文字本身也可能包含个人信息。使用者应妥善保护这些文件，不要直接将完整工作目录公开上传。

模型下载访问 Hugging Face 及其文件分发基础设施，第三方服务会接收到下载请求相关的网络信息。点击授权页面或外部链接会打开浏览器并适用该服务自己的条款。本程序默认关闭 pyannote 使用统计和 Hugging Face 遥测。

## Token

普通转写以及完整本地模型运行不需要 Token。在线下载受访问条件限制的模型时，Token 用于向模型服务验证读取权限，不会作为转写内容发送。

保存的 Token 使用当前 Windows 用户的密钥加密，独立于普通设置文件。清空主界面的 Token 输入框后正常关闭窗口，会删除本程序保存的 Token；外部设置的环境变量需由用户自行清除。不要分享 Token、加密 Token 文件、账号截图或未经处理的日志。

## 使用范围和结果

请仅处理自己有权使用的录音和视频，尊重相关人员隐私及适用规则。说话人分组不是身份认证。自动转写可能有错误、遗漏或虚构文字，不能代替原始录音，重要内容需人工核对。
