# 发布与维护

## 项目定位和页面安排

仓库建议名：speech-transcription-desktop。简介：Windows 本地音视频批量转写工具，提供中文界面、CPU/GPU 选择和可选说话人区分。

首页采用根目录 README.md，展示两种下载方式、实际功能、三步使用、已知边界、许可与隐私、反馈入口。English 简介使用 README.en.md。首次 Release 使用 docs/首次发布公告.md；GitHub 发布页中教程链接应指向相应版本仓库文件。

本版按 v0.1.0-beta.1 发布，勾选 Pre-release，说明属于首次公开测试。不要填写未验证的准确率、速度倍数、最低硬件或“绝对隐私/完全兼容”等宣传词。

## 上传内容

1. 源码包解压后的目录结构就是仓库内容：根目录放 README、docs、许可与 .github，app 内放程序和测试，portable_runtime 内仅保留小型 Silero 人声检测组件。不要把整个便携 Python、个人目录或大型转写模型提交进 Git 历史。
2. 两个 Windows ZIP 是同一程序的不同资源组合，无需维护两个仓库。
3. Release 同时提供 SHA256SUMS.txt、第三方源码资料.zip 和清楚的下载位置。大 ZIP 可用网盘提供；GitHub 单个 Release 附件须小于 2 GiB。需要分卷时，先将每卷限制在约 1900 MiB，并明确“全部下载后解压第一卷”。
4. 发布前将公告中的下载位置写实，核对外部下载链接、版本和校验值。不要发布指向空位置的下载按钮。
5. 第三方源码资料包应与便携包一起保留下载渠道；以后更新组件时同步更新来源、许可、版本与哈希。

## 赞助

尚未提供真实收款方式，因此本版使用“赞助入口尚未开放”的诚实说明，不生成假二维码或示例收款地址。

记录源码版本、依赖版本、两个压缩包和第三方源码包的哈希、实际启动路径、空缓存下载结果、离线转写结果和未覆盖条件。请在一台未装开发环境的 Windows 电脑上完成外部试用后再把版本标为稳定版。
