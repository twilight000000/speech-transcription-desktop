# v0.1.0-beta.1：本地音视频批量转写，首次公开测试

这是一个面向 Windows 用户的中文语音转文字桌面工具。它把本地转写、批量处理、模型准备和可选说话人区分整理到一个界面中，希望减少反复搭环境、找模型和处理输出文件的步骤。

程序使用 WhisperX、faster-whisper、pyannote 和 Silero 等开源项目。这里的工作主要在桌面流程、便携环境、批量任务和使用体验上，没有训练新的识别模型。

这也是我第一次尝试做程序、第一次把项目开源出来，还在边做边学。虽然发布前做了一些检查，程序功能、使用说明，以及开源流程、许可标注和公告表达上，仍可能有考虑不周或写得不准确的地方。如果你发现了问题，欢迎通过 Issues 告诉我；我会认真核对，并在能力和时间允许的范围内尽力修正。也请在正式处理重要资料前，先用少量文件试用、保留原文件，并核对转写结果。感谢你的理解和耐心。

## 两种下载方式

- **按需下载模型版**：包含程序和 Python 运行环境，解压后通过引导下载当前设置需要的模型。普通转写无需账号；在线下载说话人模型需接受 Hugging Face 对应条件并填写读取 Token。
- **含模型完整版**：预装转写与说话人模型，完整解压后即可在本机使用，内置模型不需要 Token。

请从本次 Release 附件或发布者提供的下载位置获取对应文件，并核对 SHA256SUMS.txt。分卷文件必须全部下载后一起解压。“Code → Download ZIP”是源码，不是便携包。

## 这一版包含

本地音视频批量转写、TXT 和可选 JSON、识别语言与 CPU/GPU 选择、模型准备引导、按完成文件续跑、暂停/继续/停止，以及可选说话人区分。不同扩展名的同名媒体会分别保存结果，降低覆盖风险。

第一次使用先阅读 [联网下载版教程](快速开始-联网下载模型.md) 或 [完整包教程](快速开始-含模型.md)。

## 已知边界

这是首次公开测试版，尚未覆盖所有电脑和音视频编码。没有字幕时间轴编辑、实时麦克风转写和 SRT/VTT 导出。自动转写和说话人标签需要人工检查；已完成文件可以跳过，未完成的单个文件仍需重新处理。
