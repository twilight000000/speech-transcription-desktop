# v0.1.0-beta.1：第一个公开测试版

大家好，这是我第一次做程序，也是第一次在 GitHub 上发自己的项目。先把这个测试版放出来，欢迎大家下载试试。

这是一个在 Windows 上用的语音转文字小工具。选好音频、视频所在的文件夹，就可以批量转成文字。文件在自己的电脑上处理，下载包里也带好了运行环境，不用另外装 Python。

目前可以选 CPU 或 NVIDIA 显卡，导出 TXT，也可以另存 JSON。需要的话可以打开“区分不同说话人”。任务中途可以暂停或停止，下次再处理时能跳过已经完成的文件。

## 下载和使用

国内下载可以走 **[123 云盘](https://1827361209.share.123pan.cn/123pan/L9Y0jv-LXq7h)**，里面是完整 ZIP。两个版本选一个就行：

- **含模型完整版**：下载 `Windows-含模型.zip`，模型已经放好了，适合想直接用的人。
- **按需下载模型版**：下载 `Windows-按需下载模型.zip`，启动后按提示下载需要的模型。

完整解压后，双击文件夹里的 **`启动.cmd`**。不要在压缩软件里直接运行。具体操作可以看[完整版教程](https://github.com/twilight000000/speech-transcription-desktop/blob/main/docs/快速开始-含模型.md)或[按需下载版教程](https://github.com/twilight000000/speech-transcription-desktop/blob/main/docs/快速开始-联网下载模型.md)。

普通转写不需要账号。按需版如果要在线下载说话人模型，需要按引导在 Hugging Face 同意模型条款，再填入读取 Token；完整版里已有的模型不需要这一步。

如果网盘不方便，也可以用 GitHub 下载：

| 版本 | 需要下载的分卷 |
| --- | --- |
| 按需下载模型版 | [001](https://github.com/twilight000000/speech-transcription-desktop/releases/download/v0.1.0-beta.1/speech-transcription-windows-online.zip.001) · [002](https://github.com/twilight000000/speech-transcription-desktop/releases/download/v0.1.0-beta.1/speech-transcription-windows-online.zip.002) |
| 含模型完整版 | [001](https://github.com/twilight000000/speech-transcription-desktop/releases/download/v0.1.0-beta.1/speech-transcription-windows-offline.zip.001) · [002](https://github.com/twilight000000/speech-transcription-desktop/releases/download/v0.1.0-beta.1/speech-transcription-windows-offline.zip.002) · [003](https://github.com/twilight000000/speech-transcription-desktop/releases/download/v0.1.0-beta.1/speech-transcription-windows-offline.zip.003) |

同一版本的分卷要全部下载到同一个文件夹，再用 7-Zip 打开 `.001` 解压。

网盘放的是注释精简版，功能与 GitHub 版相同，但 ZIP 的校验值不同。核对文件时请选对应的清单：[123 云盘包校验值](https://github.com/twilight000000/speech-transcription-desktop/blob/main/docs/SHA256SUMS-123pan.txt) · [GitHub 分卷校验值](https://github.com/twilight000000/speech-transcription-desktop/releases/download/v0.1.0-beta.1/SHA256SUMS.txt) · [GitHub 整包校验值](https://github.com/twilight000000/speech-transcription-desktop/releases/download/v0.1.0-beta.1/SHA256SUMS-full.txt)。

## 遇到问题可以告诉我

我还在边做边学，程序可能有没考虑到的问题，教程、许可说明和开源流程上也可能有疏漏。如果你发现了，欢迎到 [Issues](https://github.com/twilight000000/speech-transcription-desktop/issues) 提醒我，我会核对后修改。反馈时带上电脑配置、操作步骤和报错，会更容易找到原因；记得把 Token 和私人录音等信息去掉。

这是测试版，还没有在各种电脑上都试过。第一次用可以先拿一小段录音试试，保留原文件，转写结果也检查一下。现在还没有实时麦克风转写、字幕时间轴编辑和 SRT/VTT 导出；中断时没完成的那个文件需要重新处理。

识别部分用到了 WhisperX、faster-whisper、pyannote 和 Silero，感谢这些开源项目和作者。我的工作主要是把中文界面、批量任务和模型准备这些步骤整理到一起，方便在本地使用。项目代码采用 [GPL-3.0-only](https://github.com/twilight000000/speech-transcription-desktop/blob/main/LICENSE)，模型和第三方组件各自的许可也整理在[项目说明](https://github.com/twilight000000/speech-transcription-desktop/blob/main/THIRD_PARTY_NOTICES.md)里。

想看代码或自己修改，可以下载[此版本源码](https://github.com/twilight000000/speech-transcription-desktop/archive/refs/tags/v0.1.0-beta.1.zip)；相关组件的[第三方源码资料](https://github.com/twilight000000/speech-transcription-desktop/releases/download/v0.1.0-beta.1/third-party-sources.zip)也保留着。日常使用不用额外下载这两份。
