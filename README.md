# 语音转文字桌面工具

把本地音频、视频批量转成文字。面向 Windows 用户，提供中文桌面界面，可选择 CPU 或 NVIDIA GPU，并按需区分说话人。

**当前版本：v0.1.0-beta.1，首次公开测试版。** 本项目把 WhisperX、faster-whisper、pyannote 等已有工具整理为便于本地使用的流程；不声称自研识别模型，也不承诺特定准确率。

## 下载哪一个

请在项目的 **Releases（发布版本）** 页面选择发布包。GitHub 的 **Code → Download ZIP** 是源码，需要开发环境，不能代替下面的便携包。

| 版本 | 适合谁 | 第一次使用 | 账号 |
| --- | --- | --- | --- |
| Windows-按需下载模型.zip | 希望只下载实际需要的模型 | 完整解压，双击“启动.cmd”，按引导下载模型 | 普通转写无需账号；在线下载说话人模型需 Hugging Face 账号与读取 Token |
| Windows-含模型.zip | 希望准备好后离线使用，或不方便访问模型网站 | 完整解压，双击“启动.cmd” | 内置模型本地运行不需要 Token |

两种便携包均包含 Python 和运行依赖，无需另装 Python。按需下载版也带有较大的 CPU/GPU 运行环境，并不是几 MB 的小安装器。两种版本使用相同源码；区别是是否预装转写与说话人模型。内置人声检测组件两版都有。

## 能做什么

- 选择一个文件夹，递归处理其中支持的音频和视频，保留子目录结构。
- 输出带时间戳的 TXT，可选输出 JSON。
- 按文件跳过已有结果，中断后继续剩余文件；同名不同扩展名的媒体分别保存。
- 选择识别语言、处理档位与 CPU/GPU 模式，查看进度、暂停、继续或停止。
- 按需区分不同说话人；分离失败时可选择仅转写继续。
- 缺少模型时显示准备引导，支持取消后重试、版本固定与下载校验。

目前不提供在线协作、字幕时间轴编辑、画面文字识别、实时麦克风转写或一键导出 SRT/VTT。结果需要人工复核，尤其是人名、数字、方言、多人重叠和噪声片段。

## 三步使用

1. 完整解压到可写的本地文件夹，双击根目录的 **启动.cmd**。不要在压缩软件内直接运行。
2. 选择输入、输出文件夹；第一次建议“均衡”，只需要文字时保持“区分不同说话人”关闭。点击 **首次使用 / 模型** 查看准备状态。
3. 模型就绪后点击 **开始转写**，完成后点击 **打开输出目录**。例如 `会议.mp4` 对应 `会议.mp4.txt`。

面向 Windows 10/11 64 位。建议至少 16 GB 内存，预留 25 GB 磁盘空间用于压缩包、解压文件与结果。GPU 模式需要支持 CUDA 的 NVIDIA 显卡和兼容驱动；不可用时选择 CPU。处理速度和内存占用取决于模型、音频长度与电脑配置。

## 隐私、许可与赞助
